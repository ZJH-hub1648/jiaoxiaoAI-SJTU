# Skill 隐私与存储

本 Skill 无作者服务器、遥测或自动模型调用。默认 Agent 工具在本机提取 PDF、OCR、检索与准备证据，由 **当前宿主 Agent 模型** 生成解读。证据进入宿主上下文，可能由该宿主选择的模型服务处理；“不需要额外 API Key”不代表“内容绝不出设备”。

默认数据目录：`~/.config/jiaoxiaoai-paper/`，可用 `PAPER_READER_DATA_DIR` 或 `--data-dir` 改变。目录下 `papers/` 保存 PDF、提取文本、OCR、注释、问答与区域图；`jobs/` 保存当前 Agent 的准备任务和阅读器问题，包含论文片段及可能的本地图像；`comparisons.json` 保存已完成对照；`ocr-languages/` 为本机识别数据缓存。

请把这些目录放在用户私有位置。文件尽量使用 `0600`、目录 `0700`；Windows 取决于账户 ACL，不是加密保险库。阅读器的论文删除会删除该篇文档及记录，但已准备的任务和比较片段可能仍在历史文件。若需清除全部论文资料，先停止阅读器、MCP 和 CLI，再删除自己明确指定的数据目录；不要删除未知共享目录。

只有用户选择独立模型模式时才向配置的 API/Ollama 服务发请求，密钥存入 `model.json`，读取配置的 API 不返回密钥。宿主模式不读取宿主私有模型配置，也不需要把 Key 发给 Agent。

阅读器图像解读需要单独确认图像发送；宿主 Agent 处理图像前应具有用户要求并说明资料会进入当前模型上下文。OCR 自身完全在本机完成。安装 npm 依赖会访问软件分发服务，但不发送论文或模型凭据。

源码和独立 ZIP 排除数据、密钥、缓存、依赖目录及历史 ZIP。生成结果仍可能有误，原文引文匹配或页码验证不等于学术结论已被证明。
