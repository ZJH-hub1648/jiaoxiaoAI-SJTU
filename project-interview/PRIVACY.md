# 面试数据与模型边界

- 项目索引为静态读取：Git 只用于文件列表和 HEAD，不运行项目命令、测试、依赖脚本，不上传仓库。项目依赖与 MCP 工具自身的依赖是两回事。
- 默认私有目录 `~/.config/jiaoxiaoai-interview/` 存放 snapshots（源码片段、路径、哈希、简历主张）、sessions（问题、用户回答、提示、评价）、jobs（版本绑定任务）、locks（并发控制）。`PROJECT_INTERVIEW_DATA_DIR` 或 `--data-dir` 可改绝对目录，不允许与被索引项目重叠。不要将此目录或导出的报告公开提交。
- 默认过滤常见密钥路径、部分凭据内容模式、符号链接、依赖和生成目录；这不是通用脱敏器，无法保证排除任意业务机密。索引前请提供脱敏项目。简历支持 UTF-8 TXT/Markdown，最多 64 KiB；不收集学校 Canvas Token。
- 选择的代码/简历/回答/评分任务会作为工具输出进入宿主 Agent，其是否发送到远程模型以及保存多久，由宿主和模型服务的数据政策决定。Skill 不读取或导出宿主的模型 Key，也不提供独立模型代理接口。
- 本机文件使用私有目录和 0600 文件权限请求；Windows 实际访问控制取决于父目录 ACL。不要把默认目录放到共享或公开同步位置。发布/安装白名单排除个人记录、依赖目录和旧 ZIP。
- 导出为用户指定的私有新文件，不覆盖旧文件；Markdown 对输入标记转义。需要删除记录时，可在停止相关 CLI/MCP 进程并确认路径后删除对应私有文件/目录；工具没有远程删除能力，也不会自动移除宿主已收到的上下文。
- 评分由宿主模型生成。程序校验引用、回答摘录、数值范围和任务版本，不能证明模型语义评价正确、公平或符合实际招聘标准。独立指标只排除**已记录**的提示，不能检测未报告的外部帮助。历史复盘不声称当前代码仍未变化。
